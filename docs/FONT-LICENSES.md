# Fonts

All fonts used by the Style Packs are Google Fonts released under the **SIL Open Font License 1.1** (https://openfontlicense.org), which allows free use, including in commercial videos. They are loaded at render time with `@remotion/google-fonts` (only the weights and the Latin subset each pack needs), so no font files are stored in this repo.

| Font | Used by | Licence |
|---|---|---|
| Instrument Serif | Lab Notes | OFL 1.1 |
| JetBrains Mono | Lab Notes, Explainer UI (labels) | OFL 1.1 |
| Inter | Lab Notes, Studio Ad, Explainer UI, Highlighter Doc, Portrait Mono (captions) | OFL 1.1 |
| Bricolage Grotesque | Studio Ad | OFL 1.1 |
| Inter Tight | Explainer UI | OFL 1.1 |
| Newsreader | Highlighter Doc | OFL 1.1 |
| Anton | Bold Poster | OFL 1.1 |
| Archivo | Bold Poster | OFL 1.1 |
| Courier Prime | Portrait Mono | OFL 1.1 |
| Montserrat | Creator Pop, classic themes | OFL 1.1 |
| Caveat | Handwritten Journal | OFL 1.1 |
| Patrick Hand | Handwritten Journal | OFL 1.1 |

Hindi and Gujarati text falls back to the Noto fonts installed on the render machine (OFL 1.1). Emoji use Noto Color Emoji on the runner (OFL 1.1).
